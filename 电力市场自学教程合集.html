第一讲 · 线性规划与对偶

1.1 线性规划三要素

线性规划（Linear Programming, LP）：在线性约束下，最大化/最小化一个线性目标。

决策变量 x
目标 min/max cᵀx
约束 Ax ≤ b, x ≥ 0
例题 · 最小化购电成本（出清模型的雏形）

两台机组，负荷 300 MW：机组 A（成本 300 元/MWh，容量 200 MW），机组 B（成本 600 元/MWh，容量 200 MW）。

LP 模型：决策 xA, xB（各发多少）；

min 300·xA + 600·xB
s.t.　xA + xB = 300
　　 0 ≤ xA ≤ 200
　　 0 ≤ xB ≤ 200

最优解：xA=200，xB=100，成本 = 300×200 + 600×100 = 120,000 元。边际机组是 B，影子价 600。

1.2 对偶：为什么 LMP 就是"影子价格"

每个约束对应一个对偶变量（影子价格）：约束右端项 +1 单位时，目标函数值的变化量。

关键衔接：在出清模型里，负荷平衡约束（xA+xB=300）的影子价格 = 节点边际电价 LMP。负荷 +1 MW，总成本 +600 元 → LMP = 600。这就是阶段1"LMP = 再多供 1 MW 的最小成本增量"的数学本质——LMP 就是对偶变量。

同理，线路容量约束的影子价格 = 阻塞分量（阶段1的 LMP 阻塞分量）。所以学懂对偶，就理解了整个定价逻辑。

第四讲 · Pyomo / Gurobi 建模入门

优化求解器的通用三步：①定义变量 → ②写目标与约束 → ③求解取结果。Pyomo 用 Python 建模，Gurobi 是高性能求解器。

from pyomo.environ import *
m = ConcreteModel()
# ① 变量
m.xA = Var(bounds=(0, 200)); m.xB = Var(bounds=(0, 200))
# ② 目标 + 约束
m.obj = Objective(expr=300*m.xA + 600*m.xB, sense=minimize)
m.bal = Constraint(expr=m.xA + m.xB == 300)
# ③ 求解
SolverFactory("gurobi").solve(m)
print("xA =", m.xA(), "xB =", m.xB(), "cost =", m.obj())

依赖：pip install pyomo；求解器可选 Gurobi（需 license）或免费 CBC/glpk。

阶段0 只需跑通这个 3 台机组的 LP，建立"写模型 → 求解"的手感；复杂模型（含 0-1 变量的 UC）留给阶段4。

导读：一条主线贯穿全文

金融里你熟悉的商品（股票、债券、黄金、原油）都有一个共同点：可以存起来。原油能进油罐，黄金能进金库，股票可以持仓不动。

但电几乎存不下来（大规模储能昂贵且有限）。于是出现了一条铁律：

发电 = 用电 + 损耗，必须每时每刻实时平衡。一旦不平衡，电网频率就会偏离 50 赫兹（中国标准），轻则设备受损，重则大面积停电。

这条铁律派生出了后面几乎所有的知识点：

铁律的推论对应知识点
没人能"囤货待涨"，需求多少就发多少负荷曲线、机组必须实时可调
机组不能瞬时启停、瞬时变速爬坡率、启停成本、最小出力
要防意外，必须预留调节能力备用
电要顺着电网流，线路有容量上限阻塞、网损
价格由"最后一度电的成本"决定边际成本定价、统一出清
线路堵了，各地点价格不同节点电价 LMP、分区电价、阻塞盈余

全文就讲这一件事：一个"存不住、还实时要求平衡"的商品，它的价格到底怎么定。学完你会自然理解为什么会出现 0 元电价甚至负电价。

第一讲 · 电力系统物理基础

1.1 发-输-配-用：电是怎么到你家的

电从发电厂到你家的插座，要经过四段旅程。因为输电要抬高电压、降低电流，才能减少线路损耗（损耗与电流的平方成正比），所以"高压输电、逐级降压"。

图1　电力系统结构：发电 → 升压 → 输电 → 降压 → 配电 → 用户
关键点：输电环节电压高、电流小、损耗低；配电环节电压低、直接入户。对市场来说，记住一点就够了——电从发到用是"即产即消"的，整个链条没有仓库。

1.2 负荷曲线：需求随时间怎么变

全社会每一刻的用电需求连起来，就是负荷曲线（Load Curve）。它一天有两个高峰（午高峰、晚高峰）、一个深夜低谷。

图2　典型日负荷曲线：双峰（午高峰 + 晚高峰）+ 深夜低谷；按高度分为基荷 / 腰荷 / 峰荷

负荷曲线的三个区域对应三类机组分工：

负荷带时间谁来发特点
基荷全天 24h核电、大煤电成本低、不愿频繁调节，稳稳发
腰荷白天大部分煤电、气电、水电可调，跟着负荷上下
峰荷早/晚高峰气电、抽蓄、储能启停快、成本高，只赚高峰的钱

1.3 机组类型与成本特性

不同机组"快慢"和"贵贱"差别巨大，这是理解电价的关键。先看一张表：

机组边际成本启停速度爬坡能力角色
风电 / 光伏≈ 0 元/MWh看天吃饭不可控优先发（边际成本低）
核电很低极慢基本不调基荷
煤电中（约 300）慢（启停以小时计）中基荷 / 腰荷
气电较高（约 600）快（分钟级）快峰荷 / 调节
燃油 / 储能放电很高（约 1200+）很快快尖峰 / 应急

表中数值为便于理解的示意值，各地区燃料价格与规则不同，实际成本会变。

把这些机组按边际成本从低到高排队，就得到一条阶梯状的供给曲线（merit order，优序/报价排序）：

图3　优序供给曲线（merit order）：边际成本从低到高排序，形成阶梯
记住这张阶梯图——它就是后面"出清"和"定价"的全部基础。负荷越往右，需要的机组越贵，价格越高。

1.4 物理约束：爬坡 / 启停 / 最小出力 / 备用

这些约束让"电"和"普通商品"彻底区分开：

约束含义生活类比
爬坡率机组每分钟最多能加/减多少出力，不能瞬间跳变油门不能一脚踩到底，只能慢慢加
启停成本开机要烧煤/气暖机，停机再启动又慢又贵锅炉点一次火很费时费钱
最小出力机组不能太低出力运行，否则不稳定车怠速也不能太低，会熄火
备用预留的调节能力，应对预测偏差和突发故障备胎 / 消防队随时待命
为什么这些约束影响电价？因为负荷是实时跳动的，而机组又"不能想发就发、想停就停"。于是系统必须提前调度、预留备用，这些"摩擦成本"最终都会体现在价格里。

1.5 电网的物理约束：阻塞与网损

阻塞（Congestion）：线路有"运力上限"

每条输电线都有容量上限。当便宜的电力想从 A 送到 B，但线路满了，就出现了阻塞——便宜的电过不去，只能让 B 当地更贵的机组顶上。

图4　两节点电网：A 的电便宜但线路只能送 200，B 缺的 200 只能由本地贵机组顶上 → 阻塞

网损（Loss）：传输有损耗

电在导线上传输会发热损耗，损耗与电流的平方成正比（I²R），所以距离越远、潮流越大，损耗越多。对电价的影响：

网损分量 ≈ 边际网损率 × 系统边际成本

例如某节点边际网损率 5%，系统边际成本 300 元/MWh，则该节点网损分量 ≈ 15 元/MWh，远端节点的电价更高。

第二讲 · 电力市场经济学（上）：边际成本与统一出清

2.1 微观经济学热身

电力市场的定价，本质是微观经济学里最经典的一张图——供给与需求。只需要回忆三个概念：

概念含义在电力市场里对应什么
边际成本 MC多生产 1 单位，总成本增加多少机组再多发 1 度电要烧多少燃料
完全竞争均衡价供给=需求时的价格 P*市场出清价（MCP）
边际定价原则竞争市场里 P = MC电价 = 最后一台被调用的机组成本
一句话：在完全竞争市场里，价格由"边际"决定，不由"平均"决定。这是理解电价的钥匙。

2.2 为什么是"边际成本"定价，而不是"平均成本"？

举例 · 一桌菜的"最后一盘"

一家餐厅一天卖 100 盘菜，平均每盘成本 20 元。中午突然来了大量客人，厨房已经满负荷，多炒一盘要临时加人加灶，这一盘的成本是 30 元。

请问：给这批"加单"客人定价，应该按平均成本 20，还是按边际成本 30？

答：按 30。因为如果按 20 卖，餐厅会亏掉新增那一盘（多做的成本就是 30）。只有当价格 ≥ 30 时，餐厅才愿意多炒这盘菜。决定"要不要再多发一度电"的，是那最后一度电的成本——即边际成本。

发电同理：

机组边际成本（多发 1 度电的成本）说明
风光≈ 0风吹太阳晒，不烧燃料
煤电约 300 元/MWh多烧煤的成本
气电约 600 元/MWh气比煤贵

注意：这里说的是边际成本，不含建厂、还贷等固定成本（固定成本靠边际成本之上赚的"利润"慢慢回收，这正好引出后面的容量市场）。

情形三：深夜负荷 100 MW → A 一个人就够（200>100），出清价 = 0 元（甚至当风光发太多又送不出去、储能也满时，会负电价——倒贴钱请你用电）。

第三讲 · 电力市场经济学（下）：节点电价 LMP 与市场力

3.1 为什么需要节点电价：从"全网一个价"到"每个点一个价"

统一出清假设电可以在全网自由流动、没有线路瓶颈。但真实电网有阻塞（图4）：便宜的电过不去，贵的电只能顶上。于是：

  • 节点 A（便宜电这一侧）：再多发 1 MW，成本是 300 元。
  • 节点 B（缺电这一侧）：再多用 1 MW，只能靠本地 800 元的机组，成本是 800 元。

同一个系统里，不同地点"多供应/多消费 1 MW 的真实成本不同"，所以每个地点应该有自己的价格——这就是节点边际电价（Locational Marginal Price, LMP）。

LMP 的定义：在某节点再多供 1 MW 负荷（或多消 1 MW 发电）所引起的最小系统总成本增量。它是优化问题的"影子价格"（对偶变量）。

3.2 LMP 的三个分量

LMP = 能量分量（Energy） + 阻塞分量（Congestion） + 网损分量（Loss）
分量含义生活类比
能量分量忽略阻塞与损耗时，全网统一的那部分边际成本（系统 λ）商品的基本价
阻塞分量线路堵了，导致某点必须用更贵电的那部分加价堵车绕路的"绕路费"
网损分量送得越远、损耗越多，多供 1 MW 损耗的补偿运输损耗的运费
图6　LMP 三分量：同一时刻，节点 A 只有能量分量，节点 B 多了阻塞分量
算例 2 · 节点电价 LMP（两节点阻塞，核心算例）

接图4：节点 A 有 G_A(300元, 500MW)，节点 B 有 G_B(800元, 300MW)，B 负荷 400MW，线路 A→B 容量 200MW（先忽略网损）。

  1. 看阻塞：B 需要 400，A 最多送 200，剩下 200 只能靠 B 本地 G_B。→ 线路已满，发生阻塞。
  2. 求 LMP_A：在 A 侧再多供 1 MW，由便宜的 G_A 承担，成本 +300。→ LMP_A = 300。
  3. 求 LMP_B：在 B 侧再多用 1 MW，线路已满、A 的电送不进来，只能让 G_B 多发 1 MW，成本 +800。→ LMP_B = 800。
  4. 算阻塞分量：阻塞分量 = LMP_B − LMP_A = 800 − 300 = 500 元/MWh。
  5. 算阻塞盈余：阻塞盈余 = 价差 × 潮流 = 500 × 200 = 100,000 元/h。

3.3 分区电价：节点电价的"粗粒度版"

逐节点定价计算复杂，有些市场把电网划成几个价区（Zone）：区内统一价、区与区之间可以有价差。

维度节点电价 LMP分区电价（Zonal）
粒度每个节点一个价每个价区一个价
精度高，最真实反映阻塞低，区内阻塞被"抹平"
代表美国 PJM/CAISO、中国多数省级现货欧洲北欧 Nord Pool 等多价区市场

国内省级现货市场（如山西、广东、山东等）价格形成机制多采用节点边际电价；具体以各省最新规则为准。

记忆：节点电价是"逐点算账"，分区电价是"划片算账"。前者更精细，后者更简单，是节点电价的近似。

3.4 阻塞盈余：电网"白捡"的钱去哪了

算例2里，B 侧用户按 800 买电，A 侧机组按 300 卖电，中间的 500×200 = 10 万元差价就是阻塞盈余（Congestion Rent / 阻塞租金）。

它不是电网的"利润"，而是线路容量稀缺产生的市场收益。通常的处置方式：① 返还给市场参与者；② 用于支付金融输电权（FTR/TCC，阶段3会学）；③ 用于补贴输电投资。不能由电网公司私自揣兜里，否则会激励电网"故意让线路堵着"。

3.5 市场力（Market Power）

市场力：某个市场主体能通过减少供给、抬高报价，把价格推到竞争水平之上并获利的能力。

算例 3 · 持留容量抬价（市场力的直观例子）

沿用算例1（负荷 500），原本出清价 300。假设某集团同时握有 B(煤电)和 C(气电)。

  1. 它把 B 的 200 MW 不报价（持留容量），只留 200 MW 报 300。
  2. 负荷 500 现在只能：A 200 + B 200 + C 100 = 500，边际机组变成 C，出清价从 300 抬到 600。
  3. 结果：所有中标机组都按 600 结算，该集团（持留 + 高价机）整体利润反而增加。

这就是持留容量（capacity withholding）——最经典的市场力行为。因此监管会监测报价、做市场力缓解（如价格上限、参考报价、市场力检测 RSI 等）。

记住这个分工：中长期锁大头（稳），现货发现短期价格（准）。这正是国内"中长期交易为主、现货交易为辅"的政策导向。

4.2 逐条讲透术语

日前市场（Day-Ahead, DA）
提前一天对次日每个小时购售电竞价出清，给出逐时日前价与中标量。是现货市场的"主定价场"。
类比：机票提前一天订，锁定价格。
实时市场（Real-Time, RT）
实际运行时，针对"实际与日前计划的偏差"再次平衡定价。波动更大，常是惩罚/奖励信号。
类比：临飞前改签，按当时高价。
中长期交易
年度/月度/多日的双边协商、集中竞价、挂牌交易，锁定大部分电量与价格，规避现货波动。
类比：签长期供货合同。
辅助服务
调频、备用、调压、黑启动等保障安全稳定的服务，单独交易定价。
类比：酒店的安保、消防服务。
容量市场 / 容量电价
为"可用容量"而非"电量"付费，保障长期有足够机组可用。
类比：会员费/保险，保证"随时叫得到车"。
偏差考核
实际发/用电与合同或中标量不符时，对超出允许范围的部分按规则结算费用。
类比：合同违约的违约金。
现货出清
按申报的量价，通过安全约束机组组合(SCUC)+经济调度(SCED)等优化模型算出中标量与价格。
类比：集合竞价的撮合引擎。
双结算（Dual Settlement）
日前按日前价结算日前中标量，实时按实时价结算与日前的偏差量，两者相加。
类比：先付定金，货到了多退少补。

4.3 重点展开一：双结算怎么算

图8　双结算：日前按计划结，实时按偏差结，两者相加
算例 4 · 双结算（多用与少用两种情况）

情况一 · 多用：日前预测 100 MWh、日前价 300，中标 100；实时实际用了 110、实时价 600。

  • 日前结算：100 × 300 = 30,000 元
  • 实时偏差：多用了 +10 MWh × 600 = +6,000 元（买贵了）
  • 总：36,000 元

情况二 · 少用：实时实际只用 90、实时价 200。

  • 日前结算：100 × 300 = 30,000 元
  • 实时偏差：少用 −10 MWh × 200 = −2,000 元（退回来，但按便宜的实时价退，亏了）
  • 总：28,000 元

核心：日前市场帮你锁定大部分量的价格（对冲），实时市场只结算那部分偏差。所以"预测准不准"直接决定成本——这正是阶段4要做的电价/负荷预测。

4.4 重点展开二：容量市场 vs 电量市场

电量市场（Energy）只付"你发了多少电"的钱；容量市场（Capacity）额外付"你准备好了、随时能发"的钱。

维度电量市场容量市场 / 容量电价
买什么电量（MWh）可用容量（MW，承诺可用）
解决什么短期供需平衡长期充裕性：怕尖峰时没机组可用
通俗类比按用量付费买保险/会员费，保证"随时叫得到车"
为什么要容量市场？因为光靠电量市场的"尖峰高价"可能不足以让电厂愿意长期投资建设——尖峰高价一年没几次，回收不确定。容量机制给了一个稳定预期。中国自 2024 年起对煤电实行容量电价机制（具体标准以国家发改委官方文件为准）。

4.5 重点展开三：偏差考核

市场要求"说到做到"。实际发/用电与合同或中标量之间的差额就是偏差电量，超出允许范围（各市场规定不同，常见 ±2%～±5%）要按规则考核。

举例 · 偏差考核

某用户中长期合同 1000 MWh/月，实际用电 900 MWh，偏差 −10%，超出允许范围（假设 ±3%）。

超出的 7%（70 MWh）按偏差考核规则结算，可能产生额外费用。各省允许偏差范围和考核价规则不同，务必以当地规则为准。

偏差考核是阶段2、阶段3（售电公司风险对冲）的重点，阶段1先理解"有偏差就要算钱、就要担风险"即可。

第六讲 · 自测与常见误区

6.1 自测题（先答，再展开看答案）

1. 为什么电价由"边际机组"而非"平均成本"决定？
因为决定"要不要再多发一度电"的，是那一度电的增量成本（边际成本）。竞争市场里 P = MC，所以价格落在最后一台被调用的机组成本上，而不是所有机组的平均成本。
2. 3 台机组（边际成本 10/30/80 元），负荷 2.5 台，出清价是多少？
按价排队：10 元机组先出满，30 元机组再出满（累计 2 台），还剩 0.5 台由 80 元机组出。最后一台被调用的是 80 元机组，所以出清价 = 80 元。
3. 统一出清价 vs 节点电价（LMP）的本质区别？为什么有阻塞必须用 LMP？
统一出清假设全网一个价、无线路瓶颈；LMP 承认每个节点"多供/多消 1 MW 的成本不同"。有阻塞时，便宜电过不去、贵的电顶上，各节点成本不同，所以必须逐节点定价，否则价格信号会失真。
4. LMP 的三个分量分别是什么？各由什么决定？
① 能量分量：忽略阻塞/损耗的系统边际成本；② 阻塞分量：线路容量约束的影子价格（堵车绕路费）；③ 网损分量：边际网损 × 系统边际成本（运输损耗）。三者相加 = LMP。
5. 日前市场与实时市场的经济功能区别？双结算结的是哪两部分？
日前市场提前锁定价格、规避波动（对冲）；实时市场对实际偏差平衡定价（发现实时稀缺）。双结算 = 日前中标量×日前价 + (实际−日前)×实时价。
6. 阻塞盈余从哪来？为什么它不等于电网的"利润"？
来自"高价端用户付的钱 − 低价端机组收的钱"的差价×潮流。它是线路容量的稀缺价值，不是电网经营利润；通常要返还市场、用于支付输电权或补贴投资，若归电网则会产生"故意制造阻塞"的扭曲激励。
7. 用一句话向同行解释"备用"和"爬坡率"为什么影响电价。
因为电要实时平衡且机组不能瞬间变速，系统必须提前预留能快速调节的"备用"、并受"爬坡率"限制——这些调节能力的稀缺与摩擦成本，最终会计入价格。

6.2 常见误区

误区正解
"电价 = 平均发电成本"错。电价 = 边际机组成本（P = MC），成本低的机组赚"超边际租金"。
"阻塞盈余是电网公司赚的利润"错。它是线路稀缺价值，要返还/用于输电权，不能私留。
"负电价说明市场坏了"错。负电价是风光大发、调不下去时的正常价格信号，鼓励储能/用户多用电。
"日前和实时是一回事，重复结算"错。日前锁价格、实时清偏差，双结算 = 对冲 + 偏差，两者分工不同。
"电可以像原油一样囤起来低买高卖"错。电几乎不可存储，这是它与所有大宗商品最本质的区别，也是高波动、尖峰价的根源。

第二讲 · 中长期交易

2.1 中长期交易是什么、为什么重要

《电力中长期市场基本规则》（发改能源规〔2025〕1656号）：电力中长期交易是指对未来某一时期内交割电力产品或服务的交易，包含数年、年、月、月内（含旬、周、多日）等不同时间维度的交易。

定位：中长期市场是"压舱石"——锁定大部分电量和价格、稳定市场预期；现货市场是"发现短期价格"。国内政策导向是"中长期交易为主、现货交易为辅"。

2.2 交易品种（按交割周期）

品种标的物（交割周期）开市节奏
数年交易1 年以上电量定期开市，鼓励多年期购电协议

越靠近交割，交易周期越短、越精细，便于逐步贴近实际用电。

2.4 绿电交易：电量 + 环境价值的"双属性"

绿电交易（绿色电力交易）是以绿色电力 + 对应绿色电力环境价值（绿证）为标的物的品种。

绿电交易价格 = 电能量价格 + 绿电环境价值（二者分别明确、分开结算）

绿证随绿电交易由发电企业划转至买方账户，实现环境价值可追踪溯源。

2.5 中长期结算：差价结算 or 差量结算

中长期合同在现货市场运行时，通常转为"金融性质"（差价合约），不再物理执行，通过结算参考点与现货价差来结算：

中长期差价合约电费 = Σ [ 合约电量 ×（合约价格 − 中长期结算参考点现货电价）]

这就是阶段1讲的"双结算"里中长期合约的落地形态——锁的是"合约价 vs 现货参考价"的差。

例题1 · 中长期差价合约怎么结算

某发电企业与用户签年度合约：100 MWh @ 350 元/MWh。该月中长期结算参考点（取日前均价）为 300 元/MWh。

差价合约电费 = 100 ×（350 − 300）= +5,000 元。

含义：发电企业按 350 卖，但市场参考价只有 300，中间的 +5000 元差额由对方补足——无论现货涨跌，合约双方都按 350 锁定价格，这就是对冲。

第三讲 · 现货市场

3.1 现货市场构成与出清

《电力现货市场基本规则（试行）》（发改能源规〔2023〕1217号）：现货市场是经营主体开展日前、日内、实时电能量交易的市场，通过竞争形成体现时空价值的出清价格。

图4　现货市场时序：日前 → 日内 → 实时 → 结算（多数省采用"日前+实时"，蒙西等另有日内）
  • 日前市场：按日组织，考虑电网物理约束，以社会福利最大为目标集中优化出清，形成日前出清结果。
  • 日内市场：运行日滚动优化快速启停机组等灵活资源。
  • 实时市场：机组组合基本确定后，按超短期负荷预测和物理约束出清。

3.2 报价方式：报量报价 vs 报量不报价

方式含义谁能定价
报量报价同时申报电量（出力区间）和价格（非递减报价）有报价权，参与定价
报量不报价只报电量，不报价格作为价格接受者，不参与定价

国内现货试点：发电侧普遍"报量报价"；用户侧早期多为"报量不报价"（负荷作为刚性需求，按价格接受者参与）。新能源（山西等）多为"报量不报价"。

阶段1的"边际成本定价/统一出清"，在实操中就是发电侧报量报价、系统按优序出清；用户侧报量不报价意味着"不参与定价"，需求侧响应的价格信号传导还较弱——这是国内市场的现实特点。

3.3 价格机制与限价

现货市场价格机制分三种（《现货基本规则》第三十一条）：

机制适用
节点边际电价电网阻塞较严重、输电能力受限地区（含能量分量+阻塞分量）
分区边际电价存在明显阻塞断面的地区，按断面分几个价区
系统边际电价可不区分节点或价区，全网统一边际价

关于限价：现货市场须设定报价限价和出清限价，报价限价不超过出清限价；价格连续触及限值超一定时长后可设二级价格限值（上限一般低于正常限价）。

各省限价不同（据公开报道，2025年蒙西出清上限最高约 5 元/kWh，甘肃最低约 0.65 元/kWh；山东、浙江设负电价）。具体以各省最新规则为准。

3.4 现货市场运行三阶段

  1. 模拟试运行：检验系统功能，出清结果不结算。
  2. 结算试运行：按出清结果调度并结算（真金白银但规则仍在完善）。
  3. 正式运行：规则体系健全，连续不间断运行并结算。

截至 2026 年 9-11 月，已转正式运行的省级现货市场依次为：山西、山东、广东、甘肃、蒙西、湖北、浙江、河北南网、安徽、福建、陕西（第 11 个）。

第四讲 · 结算与偏差

4.1 两种批发结算方式

《现货基本规则》第八十四条给出电能量批发市场两种结算方式：

方式思路
方式一（全电量现货 + 差价合约）现货市场全电量按现货价结算；中长期合同电量按"合同价 − 参考点现货价"的差价结算
方式二（中长期优先 + 偏差现货）中长期合同电量按合同价结算；实际电量与合同电量的偏差按现货价结算

两种方式等价，只是记账顺序不同。国内多数省份采用方式一（差价合约）思路。

4.2 核心公式（方式一 · 发电侧）

发电侧电能量电费 = 日前全电量电费 + 实时偏差电量电费 + 中长期差价合约电费
分项公式含义
日前全电量电费Σ(日前出清电量 × 日前节点/分区边际电价)日前锁定的主电量
实时偏差电量电费Σ[(实际上网电量 − 日前出清电量) × 实时节点/分区边际电价]实际与日前的偏差
中长期差价合约电费Σ[合约电量 × (合约价格 − 结算参考点现货电价)]中长期对冲部分

4.3 完整结算算例（阶段2 核心例题）

例题2 · 某煤电机组月度结算（方式一，日前+实时+中长期）

某煤电机组某时段结算：

项目数值
中长期合约电量 / 合约价100 MWh @ 350 元/MWh
中长期结算参考点现货价（日前均价）300 元/MWh
日前市场出清电量 / 日前节点电价120 MWh @ 320 元/MWh
实际上网电量 / 实时节点电价130 MWh @ 400 元/MWh
  1. 日前全电量电费 = 120 × 320 = 38,400 元
  2. 实时偏差电量电费 = (130 − 120) × 400 = +4,000 元
  3. 中长期差价合约电费 = 100 × (350 − 300) = +5,000 元
  4. 电能量电费合计 = 38,400 + 4,000 + 5,000 = 47,400 元

读法：机组实际上网 130 MWh，其中 100 MWh 被中长期合约按 350 锁定（多赚 5000 差价），剩余 30 MWh 走现货；日前 120 与实时 130 的 10 MWh 偏差按实时 400 结算。三者相加就是完整电能量收入。

用户侧公式对称（用"实际用电量"替换"上网电量"，节点价可用统一结算点电价）。

4.4 结算周期："日清月结"与偏差电量

现货连续运行地区采用"日清月结"：按日对已执行结果清分计算，以自然月为周期出具结算依据并结算。

概念含义
结算时段结算的最小时段（多数现货省 15 分钟，形成 96 点/日）
日清分每日对已执行的量价进行清分
月结算月度结算 = 日清分累计 + 按自然月结算的科目
偏差电量实际发/用电量与合同或中标量的差额，超出允许范围按规则考核
《计量结算基本规则》强调：结算不得设置"不平衡资金池"，每项结算项目独立记录、分类疏导，按"谁产生谁负责、谁受益谁承担"原则分摊返还。

第五讲 · 辅助服务市场

辅助服务是保障电力系统安全稳定运行所需的调节能力（阶段1的"备用/爬坡"落地为可交易的服务）。《电力辅助服务市场基本规则》（发改能源规〔2025〕411号）印发，依据《关于建立健全电力辅助服务市场价格机制的通知》（发改价格〔2024〕196号）。

品种功能生活类比
调频维持频率稳定，快速响应偏差（一次/二次调频）方向盘微调
备用预留调节能力（旋转/非旋转备用）备胎 / 待命消防
调压 / 无功维持电压稳定稳压器
黑启动全黑后无电源自启动恢复应急点火
重要衔接：现货市场能完全实现调峰功能的地区，原则上不再设置与现货并行的调峰辅助服务品种（调峰已被现货的峰谷价差自然覆盖）。调频、备用可在起步阶段单独出清，具备条件后与现货联合出清。

辅助服务费用由发用电两侧按公平合理原则共同分担。

第六讲 · 容量机制 · 绿电绿证 · 碳市场

6.1 容量电价：为"可用"付费（对应阶段1的容量市场）

电量市场只付"发了多少电"的钱；容量电价付"你随时能顶上来"的钱，保障长期充裕性。

煤电容量电价（发改价格〔2023〕1501号）

  • 煤电从单一制电价改为两部制电价：电量电价（市场化形成）+ 容量电价（回收固定成本）。
  • 固定成本全国统一标准：330 元/千瓦·年；回收比例 2024-2025 年多数地方 30% 左右、转型快的地方 50% 左右；2026 年起提升至不低于 50%。
  • 容量电费按机组申报最大出力确定，纳入系统运行费用，由工商业用户按用电量分摊。
  • 考核：无法按调度指令提供申报最大出力的，按次数扣减（月内两次扣 10%、三次 50%、四次及以上 100%）。

发电侧容量电价完善（发改价格〔2026〕114号）

  • 分类完善：煤电、天然气发电、抽水蓄能、电网侧独立新型储能容量电价机制。
  • 现货连续运行后，有序建立可靠容量补偿机制——对机组"顶峰能力"按统一原则补偿。
容量电价是阶段1"容量市场≈保险"的中国落地形态。具体各省水平以官方附件与最新文件为准。

6.2 绿电绿证：环境价值的凭证

概念说明
绿证（可再生能源绿色电力证书）可再生能源电力的环境属性凭证，1 证 = 1000 千瓦时（1 MWh）绿色电量
绿电交易电能量 + 绿证"捆绑"交易，环境价值可追溯
消纳责任权重各省/主体需完成的可再生能源消费比例，靠绿证/绿电履行

绿证实现"全覆盖"（发改能源〔2023〕1044号），绿证交易规则与核发规则已建立（国能发新能规〔2024〕67号、国能发资质规〔2025〕107号）。绿电价格 = 电能量 + 环境价值，二者分开结算。

6.3 碳市场：减排成本的另一条线

全国碳排放权交易市场自 2021 年 7 月启动，率先纳入发电行业；电力企业通过配额交易管理碳排放成本。碳市场与绿电绿证共同构成"减排/绿色属性"的市场化激励。

碳市场的配额、CCER、纳入行业、价格等以生态环境部官方发布为准；本教程阶段2 只做定位，深入专题留待阶段5。

第七讲 · 代理购电与售电公司

7.1 谁在卖电给用户：三条路径

图5　用户购电三条路径：①直接参与批发市场（用户即购电方，无中间环节）②通过售电公司（零售）③电网企业代理购电

关键：用户不能同时参与批发市场和零售市场；暂未直接入市的用户由电网企业代理购电。

7.2 代理购电：电网兜底的"过渡通道"

取消工商业目录销售电价后，暂未直接参与市场的工商业用户由电网企业代理购电（发改办价格〔2021〕809号）。

  • 电网企业以"报量不报价"、作为价格接受者参与市场出清购电。
  • 代理购电用户电价 = 代理购电价格（平均上网电价+辅助服务费等）+ 输配电价 + 政府性基金及附加。
  • 代理购电的偏差电量按现货市场价格结算（现货运行地区）。
  • 居民、农业用电由电网保障、价格稳定，其新增损益由工商业用户分摊/分享。
方向是不断缩小代理购电范围，推动更多工商业用户直接入市。

7.3 售电公司：批发买、零售卖的"价差生意"

售电公司在零售市场与用户确立售电关系，在批发市场开展购售电（《售电公司管理办法》发改体改规〔2021〕1595号）。

注册门槛（要点）

条件要求
资产不低于 2000 万元；资产越高可售电量上限越高（2 亿元以上不限）
人员10 名以上全职专业人员（至少 1 名高级、3 名中级职称）
履约保障按标准提交履约保函/保险（0.8 分/kWh 或 5 分/kWh 取大值）

商业模式

售电公司结算电费 = 零售市场结算电费 − 批发市场结算电费（购销价差，承担偏差风险）
例题3 · 售电公司批零价差 + 偏差风险

某售电公司代理用户，月用电 1000 MWh：

  • 零售侧收入：与用户签 420 元/MWh 固定价 → 1000 × 420 = 420,000 元
  • 批发侧成本：中长期 800 MWh @ 350 + 现货 200 MWh @ 300 → 280,000 + 60,000 = 340,000 元
  • 毛利：420,000 − 340,000 = 80,000 元（再扣输配电费、偏差考核、辅助服务分摊等）

风险点：若用户实际用电偏离预测（如实际 1100 MWh），多出的 100 MWh 要按现货价采购，若现货飙到 800 元，就多花 100×(800−420)=38,000 元，可能由盈转亏。售电公司的核心能力 = 负荷预测 + 购电组合 + 偏差管理——这正是阶段3要学的风险对冲。

保底售电

售电公司退出/违约时，由保底售电公司承接其用户；保底零售价格中长期模式下按代理购电价 1.5 倍、现货运行期间原则上不低于现货均价 2 倍——用高价倒逼用户选择正常售电。

模板 · 《广东省电力现货市场交易结算流程说明》

一、市场概述

广东采用集中式现货市场，含日前市场与实时市场，与中长期市场衔接，采用节点边际电价机制。

二、交易时序

  1. 中长期（锁价）：年度/月度/月内通过双边、集中竞价、挂牌签订合同，锁定大部分电量价格。
  2. 日前（D-1）：发电侧报量报价、用户侧报量不报价，调度机构以社会福利最大为目标集中优化出清，形成日前节点电价与机组出力。
  3. 实时（T）：按实际运行状态与超短期预测出清，形成实时节点电价，平衡与日前计划的偏差。

三、结算方式（方式一，全电量现货 + 差价合约）

电能量电费 = 日前全电量电费 + 实时偏差电量电费 + 中长期差价合约电费

四、结算流程（日清月结）

  1. 电网企业按日采集关口计量数据，提交电力交易机构。
  2. 交易机构按日清分：日前电量×日前节点价 + 偏差×实时价 + 合约差价。
  3. 交易机构在每月约定工作日出具结算依据（先核对版、后正式版）。
  4. 电网企业据结算依据编制电费账单，完成发用两侧收付款。

五、偏差与考核

实际发/用电量与合同或中标量的偏差电量，按规则结算；超出允许范围的部分进行偏差考核。

六、风险与注意

  • 节点电价有地域差异，需关注所在节点的阻塞情况。
  • 实时价波动大于日前价，预测偏差直接影响成本。
  • 规则持续修订，以广东省最新现货规则为准。
完成标准：能独立把上面六节讲清楚、并套一个例题算对月度结算，即可进入阶段3（电力金融与风险管理）。

阶段2 自测（先答，再展开看答案）

1. "中长期交易为主、现货交易为辅"里的中长期交易包含哪些时间维度？
数年、年度、月度、月内（含旬、周、多日），月内原则上按日连续开市（发改能源规〔2025〕1656号）。
2. 双边协商、集中竞价、滚动撮合、挂牌交易四者的区别？
双边=一对一谈价；集中竞价=截止时点统一申报、边际出清；滚动撮合=起止时间内随时报单、价优先时优先连续成交；挂牌=一方发要约（量+价）、另一方摘牌。
3. 现货市场有哪三种价格机制？国内为何多用节点电价？
节点边际电价、分区边际电价、系统边际电价。阻塞较严重、输电受限地区宜用节点电价（含能量+阻塞分量），故国内多数省级现货采用节点电价。
4. "方式一"结算下，发电侧电能量电费由哪三部分组成？
日前全电量电费 + 实时偏差电量电费 + 中长期差价合约电费。
5. 煤电容量电价回收固定成本的比例 2026 年起是多少？
2026 年起提升至不低于 50%（云南、四川等转型快的地方原则上不低于 70%）。
6. 售电公司的核心盈利与风险是什么？
赚批发与零售的购销价差；风险在于用户实际用电偏离预测，偏差电量按现货价采购可能亏损——核心能力是负荷预测+购电组合+偏差管理。
7. "日清月结"是什么意思？
按日对已执行结果进行量价清分，以自然月为周期出具结算依据并结算。

1.4 省间现货：集中竞价出清

省间现货是实物交易，一般1 省 = 1 个交易节点（省内严重阻塞时可设多节点）。出清方式是集中竞价：

图2　省间现货：买方落地价折算到卖方节点后，买卖双方在卖方节点撮合出清
  1. 买方在落地侧申报"电力-价格"曲线，扣除输电价格与网损后折算到卖方节点。
  2. 卖方报价从低到高排，买方折算价从高到低排。
  3. 按买卖价差递减依次撮合，价差最大的交易对优先成交，直至价差为负或通道容量用完。
卖方节点出清价 =（最后成交买方折算价 + 卖方申报价）÷ 2
买方节点出清价 = 卖方节点价 + 输电价格（含网损折价）

1.5 例题：省间现货出清算例

例题1 · 省间现货集中竞价出清

某时段，发电省（卖方节点）与受电省（买方节点）之间输电价格 + 网损折价合计 100 元/MWh。

卖方报价（从低到高）：机组 A 报 300 元（可卖 200 MW）；机组 B 报 500 元（可卖 200 MW）。

买方申报（落地价，折算到卖方节点 = 落地价 − 100）：买方 N 落地 600 → 折算 500（购 100 MW）；买方 M 落地 400 → 折算 300（购 300 MW）。

撮合（价差递减）：

  1. N(500) − A(300) = 200，价差最大，成交 min(100, 200) = 100 MW。
  2. A 剩 100；下一对 M(300) − A(300) = 0，成交 min(300, 100) = 100 MW。
  3. M 剩 200，但 B 报 500，M−B = 300−500 = −100 < 0，不再成交。

最后一笔成交对是 M−A：买方折算价 300、卖方价 300。

卖方节点出清价 =（300 + 300）÷ 2 = 300 元/MWh
买方节点出清价 = 300 + 100 = 400 元/MWh

读法：省间现货把"富余便宜电"从发电省送到受电省，价差由输电成本（100 元）填平；成交只在价差 ≥ 0 时发生，保证资源流向更缺电、愿出更高价的地方。

1.6 跨电网经营区：国网 ⇄ 南网

国网经营区与南网经营区之间的交易（跨电网经营区），由北京电力交易中心、广州电力交易中心联合组织，交易结果在跨经营区通道上物理执行，并作为两侧现货市场的运行边界。

这正是"全国统一电力市场"建设的关键一环——让国网、南网两大经营区之间的电力互济也能通过市场机制常态化开展。

2.1 福建的"电源家底"：清洁能源大省

福建的电源结构在沿海省份中很特殊——清洁能源装机和发电量占比稳定"双过半"，核电机组装机占比全国第一、已投产装机容量全国第二。

特点福建的做法与广东等的差异
① 价格机制系统边际电价（全网统一边际价）广东、山西、山东、蒙西用节点电价
② 报价方式发电侧单边报价（市场化用户接受系统边际电价）多数省用户侧"报量不报价"
③ 出清周期15 分钟滚动出清，调频与电能量独立出清多数省 15 分钟、96 点
最关键的差异是"系统边际电价"：阶段1学过，节点电价 = 能量 + 阻塞 + 网损，每个节点不同；而系统边际电价是全网一个价，不区分节点/价区。福建选择系统边际电价，意味着省内阻塞信号不通过电价直接体现，更简洁，但也少了节点价的空间信号。

日前市场出清流程（2026 年修订版要点）

  1. D-1 日 11:00 前：调度机构用安全约束机组组合（SCUC）出清开机组合。
  2. D-1 日 11:00–11:30：发电侧主体完成省间日前现货报价。
  3. D-1 日 20:00 前：用安全约束经济调度（SCED）开展日前市场出清，发布 96 点出清电量、电价与系统边际电价。

结算：以 1 小时为周期做发电侧/用电侧清分，按月结算（15 分钟出清、1 小时清分）。

第三部分 · 北交 + 福建：一条电从福建卖到浙江的完整旅程

把两部分串起来，看一度"福建富余电"怎么卖到浙江（华东负荷中心）：

  1. 中长期打底：福建某发电企业通过北京电力交易中心平台，与浙江的售电公司/用户签年度/月度中长期合同，锁定电量与价格，占用浙福特高压通道。
  2. 日前现货调剂：D-1 日，福建作为卖方节点、浙江作为买方节点，参与省间日前现货集中竞价；买方落地价折算到卖方节点后撮合，成交的富余电通过浙福特高压送出。
  3. 省内出清衔接：省间现货的卖方成交结果作为福建送端关口"负荷增量"、买方成交结果作为浙江受端"电源"，分别参与两省省内现货出清。
  4. 结算：北交出具省间交易结算依据，电网企业按"日清月结"完成收付。
一句话总结：福建在省内市场用"系统边际电价"发现省内价格；在省间市场通过北京电力交易中心把富余清洁电卖到浙江、广东——省内市场定价、省间市场配置，两层市场共同构成福建的完整交易版图。

第四部分 · 自测

1. 北京电力交易中心与广州电力交易中心的分工是什么？
北交组织国家电网经营区的跨区跨省交易，广交组织南方电网经营区；跨电网经营区（国网-南网）交易由两中心联合组织。
2. 省间现货交易与跨区跨省中长期的关系是什么？
省间现货是在"落实省间中长期交易的基础上"，利用通道剩余输电能力开展的日前/日内实物交易；中长期先占通道打底，现货用剩余能力调剂。
3. 省间现货集中竞价中，卖方节点出清价怎么算？
卖方节点出清价 =（最后成交交易对的买方折算价 + 卖方申报价）÷ 2；买方节点价 = 卖方节点价 + 输电价格（含网损折价）。
4. 福建现货市场与广东最本质的差异是什么？
福建采用系统边际电价（全网统一价、分散式、发电侧单边报价），广东采用节点边际电价（集中式、用户报量不报价）。
5. 为什么说福建是"东部沿海唯一外送型省份"？
福建清洁能源装机和发电量占比"双过半"、核电装机占比全国第一，自身电多，通过浙福特高压（→华东）、闽粤联网（→广东）向外送电。
6. 福建新能源从何时起全量进入电力市场？
2026 年 1 月 1 日起，集中式与分布式风电、光伏上网电量原则上全部进入市场。

第一讲 · 电力风险的独特来源

1.1 为什么电力不能当普通商品对冲

普通商品（原油、黄金、股票）都有库存或持仓缓冲价格；但电力几乎不可存储、必须实时平衡（阶段1的核心结论），导致现货价呈现三大特征：

特征含义通俗类比
极端尖峰高峰时段电价可冲到正常价的数倍甚至数十倍暴涨暴跌的小盘股
厚尾分布极端价出现频率远高于正态分布预测尾部风险（fat tail）
负价新能源大发、调不下去时，倒贴钱让人用电负价格资产（罕见）

第二讲 · 电力远期与差价合约（CfD）

2.1 远期 vs 期货

维度远期（Forward）期货（Futures）
交易场所场外（OTC）双边定制交易所集中、标准化
结算到期一次性结算保证金 + 逐日盯市
违约风险对手方风险高交易所中央清算，风险低

在电力市场：中长期合同（双边协商）≈ 电力远期；而标准化的电力期货国内尚未上市（广期所研发中，见第三讲）。

2.2 差价合约（CfD）：电力市场最核心的对冲工具

差价合约（Contract for Difference, CfD）：双方约定一个"合约价"，到期只结算"合约价 vs 参考价"的差价，不交割实物。

CfD 结算额 = 合约电量 ×（参考价 − 合约价）

阶段2学的中长期差价结算，本质上就是 CfD：

阶段2 公式回顾：中长期差价合约电费 = Σ[合约电量 ×（合约价格 − 结算参考点现货电价）]。这就是电力 CfD——发电侧锁"卖价"、用户侧锁"买价"，中间的现货价波动被合约价"抹平"。

政府授权合约：CfD 的"政府版"

为保证居民/农业等用电稳定、或给新能源/煤电提供收益预期，政府会签"政府授权合约"——本质也是一种差价合约，用稳定价替代波动现货价。

2.3 套期保值原理：怎么用 CfD 锁定价格

套期保值（Hedging）的核心：在现货市场有风险敞口的一方，在衍生品市场做方向相反的头寸，让两个头寸的盈亏相互抵消。

例题1 · 售电公司用中长期（CfD）锁定购电成本

某售电公司已与用户签固定价零售合同 450 元/MWh，月用电 10,000 MWh。它的风险是：批发侧购电成本上升会吃掉利润（它是"天然空头"——未来要买入电）。

对冲：买入 8,000 MWh 的中长期合约 @ 400 元/MWh（相当于持有"多头"头寸）。

情形无对冲（全走现货）有对冲（80%锁价）
现货 350（跌）成本 3,500,000，赚得多8,000×400 + 2,000×350 = 3,900,000
现货 450（平）成本 4,500,000，打平8,000×400 + 2,000×450 = 4,100,000
现货 800（涨）成本 8,000,000，大亏8,000×400 + 2,000×800 = 4,800,000

结论：对冲牺牲了"现货下跌时的超额收益"，换来"现货上涨时的损失封顶"。售电公司的经营目标是赚稳定的购销价差，而非赌价格方向，所以应把大部分电量锁定。

第三讲 · 电力期货与期权

3.1 电力期货：国内现状与国际经验

市场现状
中国电力期货尚未上市；广州期货交易所（广期所）正加快推进研发，已完成"广东电力期货合约方案"设计（贴近广东现货实际，产业认可度高）；政策层面央行五部门、广东省、广州市均支持"探索适时推出"。
国际美国 CME 集团、ICE（洲际交易所）已有基于不同电力交易区域的期货/期权合约，供发电商、零售商、大工业用户对冲。
来源：中国金融信息网、期货日报、证券时报等（2025 年报道）。电力期货上市时间以证监会、广期所官方公告为准。

广期所目前已上市工业硅、碳酸锂、多晶硅等新能源产业链期货品种——电力期货是下一步的"补短板"品种。

3.2 期权：对冲"尖峰风险"的利器

期权给了买方"权利而非义务"：在约定价格（行权价）买入/卖出。对电力市场，最重要的是用看涨期权（Call）给购电价设"天花板（cap）"。

图2　看涨期权（Call）payoff：现货价超过行权价 K 后，收益线性上升
例题2 · 用看涨期权给尖峰价设"天花板"

售电公司担心高峰时段现货价冲到 2000+。买入看涨期权：行权价 600 元/MWh，覆盖 500 MWh 高峰，期权费 20 元/MWh。

  • 情形A（现货 2000）：期权行权，500 MWh 按 600 结算，而非 2000，节省 500×(2000−600)=700,000；扣期权费 10,000，净省 690,000。
  • 情形B（现货 400）：不行权，仅损失期权费 10,000（相当于保险费）。

读法：期权是"花小钱买保险"——现货不涨时亏点期权费，现货暴涨时锁定上限。这正是对冲"尖峰风险"的标准打法。

第四讲 · 基差风险：套期保值的"不完美"

基差（Basis）= 现货价格 − 期货（或合约参考）价格。套保只能对冲"价格整体波动"，无法对冲"基差变化"。

对冲后的净敞口 = 基差风险（而非价格水平风险）

电力基差风险的来源（结合前两阶段）

来源说明
节点 vs 参考点中长期按"结算参考点"价结算，但你实际所在节点是 LMP，两者有差（阻塞分量）→ 阶段1的 LMP
区域差异跨省交易中，合约参考点与本地现货价不同
时段错配合约曲线与真实负荷曲线不匹配
注意：股票指数套保的"基差"很窄，但电力市场里节点电价差异、阻塞会让基差很大且不稳定——所以电力对冲要格外关注"你锁的价格 vs 你真正面对的价格"是不是同一个。

第五讲 · VaR / CVaR / 情景分析 / 对手方风险

5.1 VaR 与 CVaR

VaR（Value at Risk，在险价值）：给定置信度与持有期，头寸可能损失的最大金额。例如"95% 置信度下单日 VaR = 50 万"，意思是"单日损失超过 50 万的概率只有 5%"。
CVaR（Conditional VaR，条件在险价值，又称 Expected Shortfall）：损失超过 VaR的那部分损失的平均值——衡量"最坏情况下平均亏多少"。

例题3 · 现货敞口的 VaR 估算

售电公司有现货敞口 2,000 MWh，现货价日波动 σ ≈ 150 元/MWh，取 95% 置信度（z = 1.645）。

VaR ≈ 敞口 × σ × z = 2,000 × 150 × 1.645 = 493,500 元

含义：约 95% 的情况下，单日现货价不利波动造成的损失不超过约 49 万元。

为什么电力要用 CVaR 而非只看 VaR：电力价格是厚尾分布（图1），VaR 会低估极端尖峰下的损失。CVaR 关注尾部平均，更适合刻画"尖峰价、负价"这类极端事件的风险。

5.2 情景分析

对电力这种"尾部重"的市场，情景分析比单点 VaR 更直观：手动构造几个极端情景，看组合盈亏。

典型情景触发对售电公司影响
寒潮/热浪负荷飙升、燃料紧张现货价冲高，敞口亏损
新能源大发风光同时满发现货价跌甚至负价，敞口受益
燃料价格暴涨煤/气价上升边际成本抬升，全市场价上移
输电阻塞关键通道检修/故障节点价分化，局部价飙升

5.3 对手方风险

场外交易（双边中长期、CfD）存在对手方风险——对方违约不履约。电力市场的应对：

  • 售电公司履约保函/保险（阶段2：0.8 分/kWh 或 5 分/kWh 取大值）——交易前交保证金。
  • 交易所中央清算（未来电力期货）——对手方风险转移到交易所。
  • 信用评价——交易机构动态监测售电公司履约额度。

阶段3 自测（先答，再展开看答案）

1. 为什么电力现货价是"厚尾分布"，对风险管理意味着什么？
电力不可存储、需实时平衡，导致极端尖峰和负价频繁出现，价格呈厚尾分布；意味着 VaR 会低估尾部风险，需要用 CVaR 和情景分析补充。
2. 中长期差价合约（CfD）与套期保值是什么关系？
CfD 是电力市场最核心的对冲工具——用"合约价 vs 参考价"的差价锁定价格，把现货价波动风险转移出去；售电公司用它锁定购电成本。
3. 中国电力期货现状如何？
尚未上市；广期所正加快推进研发，已完成"广东电力期货合约方案"设计；国际 CME/ICE 已有成熟电力期货。
4. 看涨期权如何对冲"尖峰风险"？
买入行权价为 K 的看涨期权，现货价超过 K 时按 K 结算，相当于给购电价设了"天花板"；现货不涨时只损失期权费（保险费）。
5. 电力市场的"基差风险"主要来自哪里？

第一讲 · 价格预测链

1.1 一条预测链：负荷 → 新能源出力 → 电价

电价不是独立预测的，它由"供需"决定。所以正确的预测链条是（对应阶段1的优序出清）：

图1　价格预测链：先预测负荷与新能源出力，再推出电价（净负荷 → 边际机组）
关键概念：净负荷（net load）= 负荷 − 新能源出力。新能源越多，净负荷越低，压到边际机组越便宜 → 电价越低（甚至负价）。这就是阶段1"新能源边际成本≈0 压低电价"的量化表达。

1.2 三类预测的方法

预测对象核心特征常用方法
负荷预测温度、星期/节假日、时刻、历史负荷时序(ARIMA)、机器学习(LightGBM/XGBoost)、深度学习(LSTM)
新能源出力预测数值天气预报(风速/辐照/云量)、季节物理模型 + 统计/机器学习（NWP 后处理）
电价预测净负荷、燃料价、历史电价、阻塞机器学习、深度学习、概率预测（分位数）

点预测 vs 概率预测（syllabus 强调）

  • 点预测：给出一个数（"明天 14 点电价 500 元"）。
  • 概率预测：给出一组分位数（"50% 分位 500、90% 分位 900、10% 分位 200"）——因为电价厚尾（阶段3），只知均值不够，要知分布。
概率预测 ≈ "波动率/分布"思维。分位数回归（Quantile Regression）或预测区间（Conformal）是电价概率预测的常用工具。

1.3 评估指标

指标含义适用
MAE / RMSE平均/均方根误差点预测
分位数损失（Pinball Loss）衡量分位数预测校准度概率预测
基线对比与"朴素预测"（如持久化：明天=今天）比判断模型是否"真有用"
实用提醒：电价预测难在尖峰——MAE 低不代表"高峰抓得准"。真正赚钱靠的是把峰谷时段与拐点预测对。

第二讲 · 优化决策：四大场景

2.1 报量报价

发电商/售电公司每天要决定"报多少量、报什么价"（阶段2的报量报价）。量化视角：这是在对手报价不确定下的竞价优化——报低了少赚，报高了不中标。

方法上常建模为"对手报价分布已知 → 最大化期望收益"，属于随机优化（见第三讲）。

2.2 中长期 + 现货组合（衔接阶段3）

阶段3 讲了"对冲"的定性逻辑，阶段4 把它变成定量组合优化：

min 期望购电成本 = 中长期合约量×合约价 + 现货量×E[现货价] − 风险调整项

决策变量是"中长期锁多少、现货留多少"，约束包括偏差考核上限、风险预算（VaR/CVaR 约束）。因为现货价不确定，这是一个随机优化问题。

2.3 储能套利（阶段4 核心例题）

储能的本质是"低买高卖"：低价时充电、高价时放电，赚峰谷价差。这是一个典型的线性规划（LP）问题。

图2　储能套利：低价时段充电、高价时段放电，赚峰谷价差

2.4 需求响应 与 虚拟电厂

需求响应（Demand Response, DR）：电价高时，用户主动削减/转移负荷，赚取激励或省电费。虚拟电厂（Virtual Power Plant, VPP）：把分散的储能、可调负荷、分布式电源聚合起来，像一个电厂一样参与市场。

量化视角：DR 和 VPP 都是"把灵活资源的最优调度"问题——什么时候让负荷降低、储能放多少、报多少量价。这与储能套利同源，只是资源更分散、约束更多。

第三讲 · 方法阶梯：五种方法逐级拆解

学习顺序：线性规划 → 随机优化 → 鲁棒优化 → 模型预测控制（MPC）→ 强化学习（RL，最后）。这一讲按顺序逐个讲"是什么、怎么建模、什么时候用"。

方法核心思想解决什么问题典型场景
① 线性规划（LP）目标与约束都是线性的，确定性求解"已知价格下，最优充放/出力"储能套利、经济调度
② 随机优化不确定量用"场景 + 概率"表示，最小化期望成本"价格/负荷不确定，期望最优"中长期+现货组合、报量报价
③ 鲁棒优化不确定量落在"不确定集"内，保证最坏情况可行"不管怎么变，都不出大错"偏差考核下的保守策略
④ 模型预测控制（MPC）滚动时域：每步用最新预测重解优化，只执行第一步"实时滚动决策，边走边修正"储能实时调度、需求响应
⑤ 强化学习（RL）无模型、序贯决策，从环境交互中学习策略"复杂动态、难写模型"的问题复杂竞价策略（最后用）
一句话选型：确定性问题用 LP；有概率分布用随机优化；怕最坏情况用鲁棒优化；要滚动执行用 MPC；模型难写、数据海量才考虑 RL。

3.1 线性规划（LP）—— 一切的地基

确定性优化：目标函数与约束都是线性的（如"成本 = Σ 价格×电量"）。它已在阶段0（含对偶/影子价格）和第四讲的储能项目中落地，这里不重讲。

记住一句：后面所有方法，最后都归结为"解一系列 LP"——随机优化按场景各解一个、鲁棒优化解"最坏场景"、MPC 每个时段解一个。所以 LP 是必须打牢的地基。

3.2 随机优化 —— 用"场景"处理不确定性

不确定量（价格、负荷、新能源出力）用一组"场景 + 概率"表示，目标是最小化期望成本。决策分两阶段：

第一阶段（现在定、事后不能改）：锁定量 x
第二阶段（各场景临时调整）：现货采购 ys
min　c0·x + Σs ps·Ss·ys
s.t.　x + ys ≥ D（每个场景都要满足需求）
　　 0 ≤ x ≤ Xmax，ys ≥ 0
例题 · 售电公司该锁多少中长期（两场景）

月用电 D = 1,000 MWh；中长期价 c0 = 650 元/MWh；现货只有两种情形：低谷 200（p = 0.5）、尖峰 900（p = 0.5），期望 550 元/MWh。

锁定量 x低谷成本尖峰成本期望成本最坏成本
0（全走现货）200,000900,000550,000900,000
500（锁一半）425,000775,000600,000775,000
1,000（全锁）650,000650,000650,000650,000

读法：锁得越多，期望成本越高（因为 650 > 期望 550），但最坏成本越低。只看期望的"确定性思维"会选"不锁"（550,000），可尖峰会冲到 900,000；风险厌恶会选"锁满"（最坏 650,000）。随机优化就是把"期望 + 风险偏好"写进目标，而不是拍脑袋。

# 两阶段随机规划（Pyomo 骨架）
from pyomo.environ import *
m = ConcreteModel()
m.x = Var(bounds=(0, Xmax))                 # 第一阶段：锁定量
m.y = Var(scen, within=NonNegativeReals)    # 第二阶段：各场景现货量
m.obj = Objective(expr=c0*m.x + sum(p[s]*S[s]*m.y[s] for s in scen), sense=minimize)
m.bal = Constraint(scen, rule=lambda m,s: m.x + m.y[s] >= D)
SolverFactory("gurobi").solve(m)
局限：线性模型不加风险约束时，最优解往往"全锁"或"全不锁"（bang-bang）；现实中锁定量还受合约上限、偏差考核约束，加上约束后才会出现"部分锁定"。

3.3 鲁棒优化 —— 保证"最坏情况"

不假设概率分布，只假设不确定量落在"不确定集 U"内（如现货价在 [200, 900] 元/MWh 之间），然后让最坏情况的成本最小，或保证最坏情况不超过预算。

minx　maxS∈U C(x, S)
或等价地：C(x, S) ≤ 预算，对所有 S∈U 成立
同题对比：鲁棒 vs 随机

同一个购电问题（c0 = 650，现货 200 / 900，D = 1,000）。现在不知道概率，只知道价格在 [200, 900] 内波动。

  • 随机（风险中性）：不锁，期望成本 550,000，但最坏 900,000。
  • 鲁棒（min-max）：让最坏场景最小 → 锁满 1,000 MWh，成本固定 650,000（最坏 = 650,000）。
  • 带预算约束的鲁棒：要求"尖峰场景成本 ≤ 70 万"：
    C(x, 900) = 650x + 900(1,000 − x) = 900,000 − 250x ≤ 700,000 → x ≥ 800 MWh（至少锁 80%）。

对比：随机优化"按概率平均"，可能在高价场景很惨；鲁棒优化"只盯最坏"，不惨但期望成本更高。两者之间可用 CVaR（条件风险价值）折中。

选：要"平均最好"用随机（需要较可靠的场景/概率）；要"保证不出大事"用鲁棒（只需知道波动范围）。

3.4 模型预测控制（MPC）—— 边走边算

核心：不把计划一次算到底。每个时段只用"最新预测"重解"未来 T 个时段"，只执行当前这一步，然后时间推进、重新预测、重新求解。

  1. 测量当前状态：SOC、价格、负荷。
  2. 滚动优化：用最新预测，求解未来 T 个时段的 LP。
  3. 只执行第一步：比如只执行"本时段充/放多少"。
  4. 推进时间：t → t+1，回到第 1 步。
示意 · 储能滚动调度（3 时段，数字为示意）
时点最新价格预测离线计划（t1 一次算出）MPC 实际决策
t=1100 / 300 / 500在 t1 充电，留到 t3（500）放充电（执行）
t=2350 / 280（更新）仍等 t3提早在 t2 放电（350 > 280）
t=3280—已放完，不再动

关键：离线计划只看 t1 的预测，会"错过"提前出现的峰；MPC 每步用新预测，能把电卖在真正的高价。

MPC 不是新算法，而是"LP + 滚动"的框架；难点在"预测要实时更新"和"只执行第一步"的纪律。

3.5 强化学习（RL）—— 只做选型与路线

核心：不写模型，让智能体与市场"交互试错"，从奖励中学习"什么状态做什么动作"。

概念含义电力里的例子
状态 state当前看到的信息SOC、剩余时段、预测价格
动作 action可做的决策充/放多少、报什么价
奖励 reward动作好坏的反馈本时段套利收益
策略 policy状态 → 动作的规则学出来的调度策略
为什么放最后、且不展开：RL 要海量数据、训练不稳定、结果难解释；电力"安全第一"，生产上仍以"可解释的优化 + 规则"为主，RL 多用于前沿研究（复杂竞价、多主体博弈）。

学习路线（不展开）：马尔可夫决策过程（MDP）→ 值迭代 / Q-learning → 深度 RL（DQN、PPO）。需要时按这条线单独学。

4.3 储能套利：先手算，再 LP

例题 · 储能套利（4 时段手算）

储能参数：容量 10 MWh、功率 5 MW、往返效率 90%（放电量 = 充电量 × 0.9）。

4 个时段电价（元/MWh）：[20, 30, 150, 180]。

  1. 低价充：时段1 充 5 MWh（20×5=100 元），时段2 充 5 MWh（30×5=150 元），共充 10 MWh、成本 250 元。
  2. 高价放：可放电量 = 10×0.9 = 9 MWh。时段3 放 5 MWh（150×5=750），时段4 放 4 MWh（180×4=720），收益 1,470 元。
  3. 套利净收益 = 1,470 − 250 = 1,220 元。

这个思路推广到 96 时段（15 分钟一个点），就变成下面的 LP。

LP 数学形式（通用）

决策变量：ct（充电功率）、dt（放电功率）、st（储能电量 SOC）
目标：max Σt (λt·dt − λt·ct)
约束：
　　 st = st−1 + η·ct − dt
　　 0 ≤ st ≤ E
　　 0 ≤ ct, dt ≤ P

4.4 代码框架（Python，可直接起步）

# ========== 第一步：日前价格预测 ==========
import pandas as pd, numpy as np
import lightgbm as lgb
from sklearn.metrics import mean_absolute_error

# df: 列含 price(日前LMP), load, hour, dow, is_holiday, temp, ...
df["lag1"] = df["price"].shift(1)   # 昨日同时段价格
df["lag24"] = df["price"].shift(24) # 昨日同小时价格
df["net_load"] = df["load"] - df["renew"]  # 净负荷（关键特征）

train, test = df[:-30*24], df[-30*24:]
feats = ["lag1","lag24","load","net_load","hour","dow","temp"]
model = lgb.LGBMRegressor(n_estimators=500).fit(train[feats], train["price"])
pred = model.predict(test[feats])
print("MAE =", mean_absolute_error(test["price"], pred))

# ========== 第二步：储能充放电优化（LP） ==========
from pyomo.environ import *
T = range(len(pred)); lam = pred  # 用预测价
E_max, P_max, eta = 10.0, 5.0, 0.9

m = ConcreteModel()
m.c = Var(T, within=NonNegativeReals)   # 充电
m.d = Var(T, within=NonNegativeReals)   # 放电
m.s = Var(T, bounds=(0, E_max))          # SOC
m.obj = Objective(expr=sum(lam[t]*(m.d[t]-m.c[t]) for t in T),
                  sense=maximize)
def soc_rule(m, t):
    prev = 0.0 if t == 0 else m.s[T[t-1]]
    return m.s[t] == prev + eta*m.c[t] - m.d[t]
m.soc = Constraint(T, rule=soc_rule)
m.pc = Constraint(T, rule=lambda m,t: m.c[t] <= P_max)
m.pd = Constraint(T, rule=lambda m,t: m.d[t] <= P_max)

# 用 Gurobi / CBC / glpk 求解
SolverFactory("gurobi").solve(m)
print("套利收益 =", m.obj())

阶段4 自测（先答，再展开看答案）

1. 为什么电价预测要先预测负荷和新能源出力？
电价由"净负荷（负荷−新能源出力）×边际机组成本"决定；先预测负荷与新能源，才能推出净负荷，进而推电价。
2. 点预测和概率预测的区别？为什么电价更需概率预测？
点预测给单值，概率预测给分位数/分布；电价厚尾，均值不够，需知分布（尤其尖峰分位数）。
3. 储能套利为什么能用线性规划求解？
目标是充放收益（λ·d − λ·c）线性，SOC 平衡、功率/容量约束都是线性，故是 LP。
4. 随机优化和鲁棒优化区别？
随机优化用场景分布求期望最优；鲁棒优化用不确定集保证最坏情况可行（不需概率分布，更保守）。
5. 模型预测控制（MPC）的核心思想？
滚动时域：每步用最新预测重解整个优化问题，只执行第一步，随时间推进不断修正。
6. 为什么强化学习要放在最后学？
它需海量数据、训练不稳定、难解释；电力领域安全第一、需可解释性，应先用 LP/随机/鲁棒/MPC，RL 仅作前沿探索。
